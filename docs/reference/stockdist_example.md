# Maturity input data to gadget

Maturity input data to gadget

## Usage

``` r
stockdist_example
```

## Format

Data frame with gadget attributes containing Greenland halibut stock
distributions (i.e. maturity and sex at length data) from the Institute
of Marine Research EggaNord survey.

## Source

[Joint Russian-Norwegian Arctic Fisheries Working
Group](https://www.hi.no/hi/nettrapporter/imr-pinro-en-2023-6)
