# Sex input data to gadget

Sex input data to gadget

## Usage

``` r
sexratio_example
```

## Format

Data frame with gadget attributes containing Greenland halibut sex
distributions (i.e. sex at length data) from the Barents Sea Ecosystem
Survey.

## Source

[Joint Russian-Norwegian Arctic Fisheries Working
Group](https://www.hi.no/hi/nettrapporter/imr-pinro-en-2023-6)
