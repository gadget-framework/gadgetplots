# Length input data to gadget

Length input data to gadget

## Usage

``` r
ldist_example
```

## Format

Data frame with gadget attributes containing Greenland halibut length
distributions from the Institute of Marine Research EggaNord survey.

## Source

[Joint Russian-Norwegian Arctic Fisheries Working
Group](https://www.hi.no/hi/nettrapporter/imr-pinro-en-2023-6)
