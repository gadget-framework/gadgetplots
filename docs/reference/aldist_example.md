# Age-length input data to gadget

Age-length input data to gadget

## Usage

``` r
aldist_example
```

## Format

Data frame with gadget attributes containing Greenland halibut
age-length distributions from the Institute of Marine Research EggaNord
survey.

## Source

[Joint Russian-Norwegian Arctic Fisheries Working
Group](https://www.hi.no/hi/nettrapporter/imr-pinro-en-2023-6)
