# An example gadget.fit object.

An example gadget.fit object.

## Usage

``` r
fit
```

## Format

gadget.fit object containing an early draft of the gadget model for
Northeast Arctic Greenland halibut stock assessment. This draft is used
because the final model is too large as an example dataset.

## Source

[Joint Russian-Norwegian Arctic Fisheries Working
Group](https://www.hi.no/hi/nettrapporter/imr-pinro-en-2023-6)
